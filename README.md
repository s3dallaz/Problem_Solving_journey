# My Problem Solving Journey

Started: 2026-11-07 · Language: Python

## My rules
1. Struggle first: at least 20–30 minutes before asking for help.
2. No AI writes my solutions. I can only ask for hints (Hint 1 / Hint 2 / Hint 3).
3. Think on paper first, code second.
4. A little every day beats a lot once a week.
5. If I looked at a solution, I re-solve it from scratch 3 days later.

## The 8 steps (for every problem)
1. Read it twice. What is the input? What is the output?
2. Work out 2–3 examples by hand, including weird ones (empty, one item, negatives).
3. Brute force: the simplest way that works, in plain words.
4. Pseudocode.
5. Code.
6. Test, especially the weird cases.
7. Improve: can a dict / set / sorting / two pointers make it faster?
8. Review: write the key idea in `journal.md`.

## Folder layout
```
phase-0-basics/      ← homework from my mentor (solve in the file, run it to test)
codewars/            ← solutions I solved on Codewars (copy them here after solving)
journal.md           ← one line per problem: key idea + my mistake
```

## How to run a problem
```
python phase-0-basics/01_largest_number.py
```
All tests print PASS → done. Then ask for a review.
